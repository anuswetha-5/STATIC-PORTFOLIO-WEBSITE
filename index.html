Project Objective

The objective of this project is to design and deploy a static portfolio website using Amazon S3 and demonstrate AWS cloud services including CloudWatch, Amazon SNS, AWS CloudTrail, AWS Systems Manager and IAM concepts. The project focuses on static website hosting, monitoring, notifications, auditing and cloud infrastructure management.

AWS Services Used

Amazon S3

Hosts the static portfolio website using Static Website Hosting.

Amazon CloudWatch

Monitors AWS resources through dashboards, metrics and alarms.

Amazon SNS

Provides notifications for alerts and future website events.

AWS CloudTrail

Records AWS API activities for auditing, monitoring and troubleshooting.

AWS Systems Manager

Provides centralized infrastructure management and automation capabilities.

AWS IAM

Explored Identity and Access Management concepts for secure AWS access.
